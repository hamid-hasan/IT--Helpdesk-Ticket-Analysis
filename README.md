# IT Help Desk Ticket Analysis

## Project Overview

This project analyzes IT help desk ticket data to understand ticket volume, ticket status, categories, priorities, and engineer performance.

The project uses SQL and Power BI to analyze 500 IT support tickets and create an interactive dashboard for better understanding of help desk operations.

## Objectives

- Analyze total IT support tickets
- Track resolved, open, and in-progress tickets
- Analyze tickets by category
- Analyze tickets by priority
- Measure engineer workload
- Compare engineer performance
- Calculate ticket resolution rate
- Create an interactive Power BI dashboard

## Tools & Technologies

- MySQL
- SQL
- Power BI
- Python
- Excel / CSV

## Dataset

The dataset contains 500 IT help desk tickets.

The data includes information such as:

- Ticket ID
- Ticket Status
- Ticket Category
